# Installation from GitHub

## Step 1: Clone the Repository

```bash
git clone https://github.com/anis14109/sirikotia-app-ecosystem.git
```

## Step 2: Navigate into the Project Folder

```bash
cd sirikotia-app-ecosystem
```

## Step 3: Install Composer Dependencies

```bash
cd laravel-web-api/apps
composer install
composer install --optimize-autoloader --no-dev
php artisan optimize:clear
---
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan view:clear
```

## Step 4: Copy Environment File

```bash
cp .env.example .env
```

## Step 6: Generate Application Key

```bash
php artisan key:generate
```

## Step 7: Run Database Migrations

```bash
php artisan migrate

# if need dummy data
php artisan migrate --seed

# if need fresh database & dummy data
php artisan migrate:fresh --seed

# Run only the specific migration file
php artisan migrate --path=database/migrations/xxxx_xx_xx_xxxxxx_create_users_table.php

# 2. Seed only the specific seeder class
php artisan db:seed --class=ExamTermSeeder --force
```

## Step 8: Install Frontend Dependencies

```bash
npm install
npm run build
```

## Step 9: Start the Development Server

```bash
php artisan serve
php artisan serve --host=192.168.0.151 --port=8000
```
Or visit locally-
```
http://localhost/sirikotia-app-ecosystem/laravel-web-api/public/
http://192.168.0.151/sirikotia-app-ecosystem/laravel-web-api/public/
```
